# dsh-pet-voice 🎤

对着麦克风说一句话，[dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 桌宠照着做。

## 用法

1. 确认 **dsh-pet** 已安装并启用。
2. 打开任意会话，输入框工具栏右侧出现话筒按钮。
3. **按住**说话，**松开**结束。
4. 桌宠做出动作，并弹一句气泡说明它理解成了什么。

## 会听懂什么

| 你说 | 桌宠做什么 |
| --- | --- |
| 跳个舞 / 女仆舞 / 宅舞 | 播对应舞蹈 |
| 睡吧 / 晚安 / 去睡 | 睡下 |
| 醒醒 / 起床 | 醒来 |
| 到左边 / 到右边 / 回来 / 上去 / 下来 | 走到对应位置 |
| 扔出去 / 甩出去 | 被甩飞 |
| 吃白饭 / 吃西瓜 / 涮火锅 / 吃零食 | 播对应吃东西动画 |
| 魔方 / 撸猫 / 放烟花 / 堆雪人 / 收红包 | 播对应动画 |

也可以直接说动作的完整名字（「原地专心玩魔方」「悠闲哼歌」）。

## 识别走哪条路

`POST https://api.deepseek.com/v1/tools/asr`，由 dsh-pet 内置的 DeepSeek ASR 实现发起：

- 音频 16 kHz / 单声道 / 16 位 PCM WAV，整段发送、整段返回；
- 鉴权用 DSH 凭据里的 `DEEPSEEK_API_KEY`，由 dsh-pet 解析；
- 本插件只把音频 POST 给本机 `/dsh-pet-7340/voice/hear`（`provider=deepseek`），只收文字。

**本插件不读取、不保存、不转发任何 API Key。**

## 限制

- 需要 **dsh-pet 0.4.9+**（`/voice/hear` 与 `deepseek` 实现由它提供）。
- 需要已配置 `DEEPSEEK_API_KEY`，否则识别返回 `unsupported`。
- 录音需安全上下文：`https` 或 `localhost`。
- 单次说话上限 100 秒；识别按音频时长计费。
- 按住说话，不是唤醒词，不按住时不监听。
